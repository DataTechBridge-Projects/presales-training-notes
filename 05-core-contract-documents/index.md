# Core Contract Documents

This section covers the four documents that turn a promising deal into an executed, protected engagement: the **NDA** that lets you talk openly before a deal exists, the **MSA** that sets the legal ground rules for the relationship, the **SOW** that defines exactly what you're building and for how much, and the **change order** that keeps scope changes from quietly eroding your margin. As a pre-sales professional you won't draft these documents alone, but you'll shape the inputs that go into them — and a scoping conversation that ignores contract realities is how projects end up in disputes. By the end of this section you should be able to read any one of these four documents and immediately spot what's missing.
